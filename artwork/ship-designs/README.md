# Approved ship artwork

These transparent 60×56 PNGs preserve the approved ferry, fishing trawler and
tanker concepts, with empty decks and twenty commit containers. They are visual
regression references for the editable integer-grid artwork in
`src/git_ship/sprites.py`. The trawler references show its hook at rest.

Each design keeps the existing hull name panel and reserved cargo bank. Narrower
ships fit the superstructure beside that bank; containers and lettering retain
their original pixel sizes.
