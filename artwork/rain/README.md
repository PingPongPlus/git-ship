# Approved rain artwork

The user approved the rain preview before integration. The editable native-grid
source is `src/git_ship/rain.py`. `impact-stages.png` preserves six 17×9 snapshots
from that approved preview at ripple ages 0, .12, .3, .5, .72 and .9.

Slanted blue-gray drops end in a tiny tap, followed by a widening broken ripple.
The rain uses binary transparency and nearest-neighbor scaling. Impact sites
avoid the lighthouse, full moving hull envelopes and the optional commit footer.
Current art also occludes drops and ripples before the lighthouse beam and text
are drawn. A separate seeded random stream preserves cargo and ship placement.
